# QuantSignal

Live dashboard for [QuantSignal](https://github.com/ayoubberiane/Quant_Signal):
today's cross-sectional ranking of seven ETFs, an interactive backtest with
transaction costs and benchmarks, and Amazon's Chronos-Bolt forecasting model
tested walk-forward as a factor.

Deployed automatically from the GitHub repository; edit the code there, not
here. Educational research project, not investment advice.
